# 🤖 AI Personal Assistant X Flask

An AI-powered web application built using Flask that helps users get answers to their questions and summarize lengthy emails efficiently.

## 🚀 Features

- **Ask Anything:** Ask questions and receive AI-generated responses.
- **Email Summarization:** Paste lengthy emails and get concise, easy-to-understand summaries.
- **Simple User Interface:** Clean and user-friendly web interface.
- **Real-Time Processing:** Displays loading indicators while generating responses.
- **Flask Backend:** Handles user requests and connects frontend functionality with backend APIs.

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python, Flask
- **AI Integration:** AI-powered response generation and summarization

## ⚙️ Installation & Setup

### 1. Clone the Repository

```bash
git clone https://github.com/palasathwik95/AI-Personal-Assistant-X-Flask.git
```

### 2. Navigate to the Project Directory

```bash
cd AI-Personal-Assistant-X-Flask
```

### 3. Create a Virtual Environment

```bash
python -m venv venv
```

### 4. Activate the Virtual Environment

**Windows:**
```bash
venv\Scripts\activate
```

**Linux / macOS:**
```bash
source venv/bin/activate
```

### 5. Install Dependencies

```bash
pip install -r requirements.txt
```

### 6. Run the Application

```bash
python app.py
```

Open your browser and visit:

```text
http://127.0.0.1:5000/
```

## 💡 How It Works

1. Open the AI Personal Assistant web application.
2. Enter any question in the Ask Anything section.
3. Click the Ask button to receive an AI-generated response.
4. Paste an email into the Summarize Email section.
5. Click Summarize to get a concise version of the email.

## 🎯 Project Objective

The main objective of this project is to simplify everyday tasks using Artificial Intelligence by providing an interactive assistant for answering questions and summarizing emails.
